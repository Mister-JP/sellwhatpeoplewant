# ADR 0000: Short decision title

- Status: Proposed
- Date: YYYY-MM-DD
- Owners: Project maintainers
- Supersedes: None
- Superseded by: None

## Context

Describe the product need, constraints, evidence, and forces that make a decision
necessary. Include enough context for a contributor who did not participate in
the original discussion.

## Decision

State the decision precisely. Define the boundary it establishes and the
invariants implementation must preserve.

## Alternatives considered

Describe credible alternatives and why they were not chosen. Do not manufacture
weak alternatives merely to make the decision look inevitable.

## Consequences

List the benefits, costs, operational implications, migration constraints, and
new risks created by the decision.

## Validation

Explain how the project will determine whether this remains the right decision.
Name measurable evidence or a future condition that would trigger reconsideration.
